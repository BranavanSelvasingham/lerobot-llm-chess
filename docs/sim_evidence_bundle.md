# Simulator Evidence Bundle

Use this focused report as the default entrypoint for simulator depth-calibration evidence. The full calibration regression suite now renders it automatically after real projection intake and the real-depth-aware visual-review refresh complete.

After a suite run, open:

- `/private/tmp/lerobot_sim/calibration_regression_suite/evidence_bundle/sim_evidence_bundle.md`
- `/private/tmp/lerobot_sim/calibration_regression_suite/evidence_bundle/sim_evidence_bundle.json`

You can still regenerate it from an existing suite summary:

```bash
python3 scripts/render_sim_evidence_bundle.py \
  /private/tmp/lerobot_sim/calibration_regression_suite/calibration_regression_summary.json
```

The standalone command writes:

- `/private/tmp/lerobot_sim/calibration_regression_suite/evidence_bundle/sim_evidence_bundle.md`
- `/private/tmp/lerobot_sim/calibration_regression_suite/evidence_bundle/sim_evidence_bundle.json`

The bundle links absolute paths for:

- `visual_review/pick_place_depth_distance_scorecard.png`
- `visual_review/pick_place_metadata_native_depth_view.png`
- `real_projection_intake/real_projection_residual_overlay_contact_sheet.png` when real-depth sidecars are comparable
- gripper and pick-place MP4 recordings when OpenCV produced them
- optional real-depth capture operator plan JSON/Markdown supplied on the command line

Missing optional artifacts are explicit and non-fatal. The default suite is expected to report `missing_real_depth_reference`; a synthetic or physical `real_capture: true` sidecar run can report `real_depth_comparable`. If no capture plan is supplied, the capture-plan rows are marked `not_supplied` rather than treated as real capture evidence.

To include an operator plan generated by `scripts/plan_real_depth_capture_session.py`:

```bash
python3 scripts/render_sim_evidence_bundle.py \
  /private/tmp/lerobot_sim/calibration_regression_suite/calibration_regression_summary.json \
  --capture-plan-json /private/tmp/lerobot_sim/real_depth_capture_plan/missing_real_depth_reference_inputs_real_depth_capture_plan.json \
  --capture-plan-md /private/tmp/lerobot_sim/real_depth_capture_plan/missing_real_depth_reference_inputs_real_depth_capture_plan.md
```

This renderer does not open cameras, move robot hardware, start GUI flows, call OpenAI, or change simulator geometry. It only summarizes artifacts that already exist.
