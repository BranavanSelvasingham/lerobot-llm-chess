CAMERA SPECIFICATIONS
══════════════════════

Main Camera (Overview):
┌──────────────────────────────────────┐
│ Purpose:  Overall scene awareness    │
│ Position: 30-50cm above board        │
│ Angle:    15-30° from vertical       │
│ Coverage: Full 8×8 board + robot     │
│                                      │
│ Resolution: 1280×720 (HD)            │
│ FPS:        30                       │
│ Aspect:     16:9                     │
│                                      │
│ Options:                             │
│ • iPhone via USB (index 1/2)         │
│ • iPhone via RTSP (network)          │
│ • USB webcam (index 0)               │
│ • Built-in laptop cam (index 0)      │
└──────────────────────────────────────┘

Gripper Camera (Last Mile):
┌──────────────────────────────────────┐
│ Purpose:  Precision gripper control  │
│ Position: 2-5cm above gripper        │
│ Angle:    Straight down              │
│ Coverage: Gripper + 5cm radius       │
│                                      │
│ Resolution: 640×480 (VGA)            │
│ FPS:        30                       │
│ Aspect:     4:3                      │
│                                      │
│ Requirements:                        │
│ • Small USB camera module            │
│ • Wide angle lens (120-160°)         │
│ • Mounted on gripper housing         │
│ • USB cable routed along arm         │
└──────────────────────────────────────┘

SOFTWARE STACK
═══════════════

Application Layer:
├─ chess_robot_ui.py / chess_robot_ui_llm.py
│  ├─ PySide6 Qt GUI
│  ├─ Dual camera panels
│  └─ Motor status displays

Camera Layer:
├─ OpenCVCamera (lerobot)
│  ├─ Main camera (index 0/1 or RTSP)
│  └─ Gripper camera (index 1/2)

Processing Layer:
├─ MonitoringThread (Qt)
│  ├─ Camera frame capture
│  ├─ Motor data reading
│  └─ Signal emission to UI

Hardware Layer:
├─ OpenCV (cv2.VideoCapture)
│  ├─ USB camera drivers
│  ├─ V4L2 (Linux)
│  └─ AVFoundation (macOS)
└─ FeetechMotorsBus
   └─ Serial communication

QUICK TEST COMMANDS
═════════════════════

Test cameras:
$ python test_dual_cameras.py

Test with specific indices:
$ python test_dual_cameras.py 0 1

List available cameras:
$ lerobot find-cameras

Run chess robot UI:
$ python chess_robot_ui.py --port /dev/ttyUSB0

Run chess robot UI with LLM:
$ python chess_robot_ui_llm.py --port /dev/ttyUSB0
